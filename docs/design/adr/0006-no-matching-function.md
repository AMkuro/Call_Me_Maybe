# ADR-0006: 該当する関数がないとき

状態: 決定(ユーザー、2026-11-08)。

## 背景
- 【解釈】該当する関数がない、または曖昧なプロンプトで、出力に何を入れるか(またはスキップするか)を
  Subject は定義していない(`docs/subject-v1.7.md` 第9章の6)。
- 【明文】出力のキーはちょうど3つで、余計なキーや文章は禁止(V.4.2)。クラッシュも禁止。

## 選択肢
- a. 必ず1つ選ぶ。
- b. 「該当なし」を表す疑似関数を入れる。出力の形式に合わない。
- c. その件をスキップして警告する。「プロンプトごとに1オブジェクト」と食い違うおそれがある。

## 決定
**a**。

- 【設計判断】関数の選択に「選ばない」という出口を作らない。
- 【設計判断】1割程度の誤りは許容する。それ以外の挙動は、Subject 違反になりかねず、防御しにくい。
- 警告の出力は付けない。

## 見直しの条件
- Subject の原文または評価の説明で、「該当なし」の扱いが示されたとき。
