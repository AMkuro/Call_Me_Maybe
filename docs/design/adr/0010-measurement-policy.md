# ADR-0010: 測定の方針

状態: 決定(ユーザー、2026-11-08)。

## 背景
- **精度の測定と時間の測定を混同しない。** これまで混同が起きてきた。文書でも、報告でも、別に書く。
- 【測定】時間の評価は、CPU の固定とスレッド数を決めた単独実行で較正している(`phys16-t8`:
  CPU 0〜15、8スレッド。`research/evo-x3/README.md`)。

## 決定
### 精度の測定
- 並列で動かしてよい。時間は問わない。

### 時間の測定
- 単独実行が理想。並列で測れるなら、それに越したことはない。ただし並列の場合は、分散を取る。
- 外れ値は除外する。基準(中央値の何倍以上、など)は、**後で決めて、この文書に記録する。**
- 【解釈】並列実行は、メモリ帯域やキャッシュを取り合って、時間を変える可能性がある(未測定)。
  確かめ方: 同じ構成を単独と並列で測り、差を見る。

### 調整のループ
- プロンプトの調整は、精度の向上と時間の調整を、ループで繰り返す(ADR-0005)。
- 各ループで、精度の結果と時間の結果を別々に記録する。

## 見直しの条件
- 並列の測定が単独と大きく違うと分かったとき、時間の測定を単独に限る。
