## 未解決の一覧
1. 関数が増えたときの関数選択の精度(ADR-0001)。関数セットを変えたテストで測る。
2. 文字列の値の細部(ADR-0003)。実装後に、必要になったら決める。
3. モデルのファイルの確認(ADR-0007)。破損はエラー、バージョン差は警告(決定)。最新版のハッシュの取り方、
   オフライン時の扱い、HF のキャッシュの blob 名の検証は未決。
4. 配布 SDK を lint の対象から外す解釈の防御力(ADR-0008)。
5. 設定ファイルの扱いと CI の関係(ADR-0009)。
6. レビュー機のモデル保存場所の正確な探し方(ADR-0009)。実機で調べる。ロックファイルの名前と置き場は、
   実装時に決める。
7. Subject が未定義の点: 5分の範囲、「全テストプロンプト」の件数、出力パス、整数相当値の表記
   (`docs/subject-v1.7.md` の第9章)。
8. `pyproject.toml` の構成の確定(ADR-0008、0009): `llm_sdk` のパス依存、`torch` の直接依存、CPU 専用の
   インデックス、GPU 版の選び方。クリーンなクローンでの検証結果は ADR-0008 に記録した。
